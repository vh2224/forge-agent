Load this mandatory procedure before the corresponding action.
Keep scope, phase, unit IDs, owner and physical CODE_DIR roots unchanged.
Keep primary_root_id, claim generation, gates and explicit model/tier/effort.
Never execute inline to bypass a refused route.
Inspect the real process and durable receipt before considering another attempt.
A valid saved response uses canonical replay/publication without a provider call.
Check result identity, input fingerprints and protected metadata before replay.
An active or unknown process prevents another writer.
A possibly writing worker requires reconciliation of every possible writer root.
Reset requires process termination proof and trusted authorship callback.
Timestamps and imported owner fields do not prove authorship.
One pending root keeps the next writer blocked.
Use recoverUnitSidecar/recoverStandaloneTask and their real native adapters.
Revalidate execution authority with the actual nativeInvocation binding.
The binding must match tool, route, model, effort, arguments and capabilities.
JSON serialization never creates a trusted native binding or recovery capability.
Correct known caller defects offline before another inference.
Record the changed packaging and verification, preserving the destination model.
At most one corrected retry at the same destination is allowed.
Timeout means cause undetermined unless evidence establishes a cause.
Timeout alone never proves destination unavailability.
Standing routing continuity permits the next valid untried candidate automatically.
Revalidate the personal authority source with the live canonical adapter.
Persist only its reference; opaque recovery capabilities are live, scoped objects.
Never ask again for a routing permission already granted by standing authority.
Functional pending IDs remain pending through restart and block dependent work.
The original cumulative additional-sidecar deadline is 60000ms, with reservations.
Do not renew that historical clock on restart, correction or native fallback.
An authorized native exception after expiry never permits another sidecar wait.
Preserve sanitized attempt telemetry, reason_code/layer and receipt references.
Unknown provider contact or model observation remains unknown.
Pending context ordering remains peek, file, durable handoff, then exact-record ack.
Rendering/dispatch failure never acknowledges the pending record.

Pause/handoff persist roots, authority reference, evidence, acceptance and questions.
Restart reloads that state and procedures before dependent work resumes.
