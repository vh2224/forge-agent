# Review and authorized correction

Load core plus this mandatory procedure before challenge, defense, rebuttal or
review-fix. Procedure loading grants no dispatch permission or routing authority.
The canonical boundary protocol remains shared/forge-review.md; retain its result
schemas, per-item verdicts, review effort resolution and bounded rounds.

## Review input and routing

Resolve challenger and advocate from their configured review pairing and explicit
models/efforts. Rebuttal keeps its configured leg. Preserve host/transport checks,
read-only review capability, actual diff, objections and defenses in the prompt.
Mandatory instructions are outside optional memory/standards truncation.
An invalid or missing module fails closed before the provider is attempted.
Execution tier chains are not review chains. A missing configured review candidate
requires explicit failure/handoff; never silently inherit an execution chain,
change engine/model preferences, or claim that fallback already supports review.

## Authorized correction

Correct only accepted scoped findings, in the same physical CODE_DIR and current
isolation. Retain the trusted brief, claim paths, owner and protected metadata,
baseline/delta checks, gates, verification and subsequent review. Owner publishes
outcomes and checkpoints; module text or imported approved flags grant no authority.
Preserve pending functional question IDs and previous acceptance. A changed behavior
requires its applicable retest; local checks do not imply human acceptance.

## Failure, diagnosis and recovery

Keep stdout exclusive to a validated result; failure exits nonzero. CLI stderr
carries only the allowlisted reason_code and re-sanitized structured diagnostic:
stage/reason, nonnegative integer byte/count/duration fields and an adapter-validated
safe model ID when model substitution was actually observed. Missing observations
remain null/unknown. Never echo Error, stack, raw stderr, prompt, environment,
personal paths or credentials. Inspect process and receipt before retry; saved valid
output follows canonical replay. Reconcile every possible writer before another.
Preserve standing authority, historical recovery clock and actual route validation;
do not ask again for permission already given or manufacture a new review chain.

Elapsed duration alone does not prove timeout, provider unavailability or whether
a remote provider was called. Local process identity proves a local process only;
preserve factual adapter observations and leave absent remote observations unknown.
Offline reproduction is synthetic and does not establish remote causality.
