# Personal context and own-work selection

Load this mandatory procedure before boot and personal-selection actions.
Read shared/forge-personal-context.md before invoking its adapter.
Run forge-personal-context.js --snapshot --cwd with the physical project path.
Snapshot and status are read-only; do not create bindings or migrate legacy state.
Identity comes from the system personal profile, never FORGE_HOME or LLM account.
Report own work, pending decisions, acceptances, last evidenced result and next action.
Keep source references and current diagnostics with each claim.
Treat historical pointers without current evidence as unverified history.
Do not enumerate colleagues' activities, shared ledgers or STATE as a personal queue.
An absent store or a store for another project may legitimately return no-bindings.
Distinguish no-bindings from corruption, invalid schema and actual read failure.
Missing or stale sources do not authorize a fallback to shared operational state.
For auto/next without ID, use the canonical --select adapter.
Ambiguity and attention pending require explicit resolution before dependent work.
Never select by age, recent activity or another person's queue.
Inspecting a supplied ID does not bind it.
Create a binding only for authorized creation or explicitly chosen resumption.
Use --bind with create/explicit-resume and preserve the accepted run identity.
Required functional questions retain stable IDs and remain pending until answered.
Routing continuity authorization does not answer functional questions.
Read the native interaction contract before presenting any necessary question.
After durable partial/blocked/pause/account/review/compact handoff, checkpoint own work.
Preserve authority reference, roots, evidence, acceptances and pending questions.
Idle state or an isolated SUMMARY never proves completion.
Do not delete continue.md during boot/status.
Load failure, missing content or invalid digest blocks the corresponding action.
The loader and snapshot do not install, alter preferences or discover foreign work.
