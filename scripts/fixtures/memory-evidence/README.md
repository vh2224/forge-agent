## Expected observations

- v1.json preserves hit before seed, tied seed/hit/confirm/promote/decay,
  existing duplicate hits, supersede/prune, and missing source provenance.
  MEM001 has five historical hits, confidence 0.7, historical promotion and
  zero independent confirmations. Publication's historical view stays separate.
- v2.json supplies four typed concepts, a verified independent reference and
  outcome-bound utility. A clean target gains one hit and +0.02 confidence;
  exposure/reobserve/utility each count once and add no ranking weight.
- mixed.json composes the v1 sequence with bound v2 rows and another milestone
  reusing T01/MEM001. Its arrival_order reorders only v2. Repeated delivery
  produces identical entries; conflicting event identity is rejected.
- invalid.json covers unknown schema, hybrid kinds, extra fields, duplicated
  local IDs, missing outcome, path-shaped ID and missing/foreign bindings.
  Invalid envelopes leave the canonical fragment unchanged.

## Ready receipt recipes

The ready members are bounded receipt templates, not portable live receipts.
v1.ready carries the legacy extraction and historical promotion still pending.
The integration binds its real temporary request fingerprint and telemetry,
then invokes runNativeMemory; old indexed IDs and receipt bytes must survive.
v2.ready carries the extraction expected in the actual accepted ready receipt.
acceptNativeMemoryResult creates the full v2 receipt, including owner registry
digest and native fingerprint. The test compares its extraction to this recipe.
Roots, paths, fingerprints and owner evidence bindings are generated by the
real APIs at runtime; fake approval or a serialized authority is never supplied.

Run `node scripts/forge-memory-evidence-integration.test.js` from the repo root.
It exercises real APIs/CLIs, restarted replay and immutable fixture hashes.
Temporary roots are removed in finally; the checked-in fixtures remain read-only.
Distribution is separately exercised by forge-memory-evidence-distribution.test.js.
These checks establish local behavior only; availability of independent evidence
in live callers, hosted CI, Node 22, deployment and UAT remain unverified.
